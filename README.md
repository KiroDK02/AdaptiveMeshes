# МКЭ на адаптивных сетках
Система численного моделирования через МКЭ - конечноэлементные решатели с адаптивным уточнением треугольных сеток с разными стратегиями. Поддерживает отрисовку сеток, результатов решения, сохранение/загрузку задач и сеток в/из файл(а). 
Так же через графический интерфейс можно задать задачу.
Пока что поддерживается только на винде, в скором времени займусь реализацией интерфейса на фреймворке Avalonia.
